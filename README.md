# Koilparampil Family

Genealogy and history of the Koilparampil family, Kerala, India.

This is the family wiki, kept as plain Markdown files so anyone can read
or correct a page directly on GitHub. There is no software to install and
nothing to maintain.

## How to fix or add something

1. Open the page you want to change from the list below.
2. Click the pencil icon (**Edit this file**) at the top right.
3. Make your change and click **Commit changes** at the bottom.

Text is written in Markdown: `**bold**`, `## a heading`, `- a bullet`,
and `[link text](<Other_Page.md>)` to point at another page. Anything you
do not recognise can be left exactly as it is.

Photographs live in the `images` folder and are shown with
`![description](<images/a/ab/Photo.jpg>)`.
